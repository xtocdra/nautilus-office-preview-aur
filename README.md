# Nautilus Office Preview — Arch Linux Packaging

Arch Linux packaging repository for
[Nautilus Office Preview](https://github.com/xtocdra/nautilus-office-preview).

Nautilus Office Preview adds DOCX, XLSX and PPTX document previews to
GNOME Nautilus using Sushi.

## Installation

### Requirements

- Arch Linux
- Git
- `base-devel`

### Build and install

Clone this repository:

```bash
git clone https://github.com/xtocdra/nautilus-office-preview-aur.git
cd nautilus-office-preview-aur
makepkg -si
```
